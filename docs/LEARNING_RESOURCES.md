# 💙 Virtual Hugs Learning Resources

Welcome to the Virtual Hugs learning hub!

Whether you are completely new to coding, design, research, or collaboration, this page contains free resources to help you build the skills needed for your role.

You do **not** need to master everything before contributing. The best way to learn is by building, asking questions, and experimenting!

---
