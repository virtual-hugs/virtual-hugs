# 💙 Virtual Hugs

Virtual Hugs is a collaborative project focused on creating a comforting online space for people having difficult days.

Through interactive activities, journaling, mini games, positive messages, and more, we hope to create an experience that helps users relax and feel supported.

## 🌟 Mission

Many online wellness spaces rely mainly on quotes and affirmations. Virtual Hugs aims to create a more interactive and personalized experience by offering different ways for users to cope with stress.

## ✨ Features

Currently planned:

- 📝 Journaling
- 🎮 Relaxing mini games
- 💌 Positive messages
- 🎵 Calming activities
- 🌱 Personalized recommendations
